# Pixel Aurora

A small random project generator built as a single-page web app.

## Features

- Random project name and tagline generator
- Category-based idea generation
- Curated stacks, palettes, and launch angles
- Responsive design for desktop and mobile

## Run locally

1. Open `index.html` in a browser, or
2. Serve the project with a lightweight local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — app structure
- `styles.css` — visual design and layout
- `script.js` — random generator logic

## Project vibe

This project is a creative “idea incubator” designed to spark new app concepts quickly.
